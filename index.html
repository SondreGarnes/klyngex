Ctrl+Tab: next terminal
Ctrl+Shift+T / W: new / close
Ctrl+Shift+G: side by side on/off
Ctrl+Shift+Z: zoom this terminal
Ctrl+Shift+F: search in this terminal
Ctrl+Shift+Up / Down: move this terminal
Ctrl+plus / minus / 0: text size
Ctrl+click: open a link
Shift+Enter: new line in an agent
Double-click a name to rename
Drag a name to reorder
